OWKR Gather Bot은 Discord에서 내전 모집과 참가·티어 확인, 대기실 안내를 지원합니다.

> 현재 정책은 검토 중인 초안입니다. 보관 기한·국외 이전 고지·법정 표시·시행일의 최종 확인이 남아 있습니다. 게시 자체가 개인정보 처리 동의를 대신하지 않습니다.

- [봇 개인정보처리방침](/owkr-docs/gather-bot/privacy)
- [봇 이용약관](/owkr-docs/gather-bot/terms)
- [문의·개인정보 수정·삭제 요청](/owkr-docs/gather-bot/support)

내전 참가자 정보와 Balance 서비스의 처리는 [참가자 개인정보처리방침](/owkr-docs/participant-privacy)을 확인해 주세요. 봇의 SQLite 기록과 Balance의 참가자 정보는 서로 다른 처리 범위입니다.
