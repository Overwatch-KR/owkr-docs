> 운영 환경 변경 사항을 반영해 검토 중입니다. Oracle 실시간 서버·Redis와 국외 저장소의 처리 범위·국외 이전 고지를 최종 대조하고 있습니다. 이 표시와 관계없이 본인 정보의 열람·수정·삭제 요청은 계속 접수합니다.

Discord 모집 봇의 처리는 [시간을달리는소녀 정책·지원 안내](/owkr-docs/gather-bot)에서 별도로 안내합니다. 이 문서는 참가자 정보와 Balance 서비스의 처리 기준입니다.

OWKR는 친목 목적의 Overwatch Discord 커뮤니티 서버입니다.

서버 내전 참가자 식별과 팀 밸런싱을 위해 아래 정보를 수집·이용합니다.

## 1. 수집하는 정보

### 필수 정보

- Discord 사용자 ID
- Discord 표시 이름
- BattleTag
- 탱커·딜러·힐러 역할별 티어
- 내전 기록

### 선택 정보

- 선호 역할 및 회피 역할
- 마이크 사용 여부
- BattleTag 변경 이력
- 내전 운영에 필요한 특이사항
- 내전 이후의 만족도 조사
- 영웅 밴 투표

실시간 공동 운영·밴픽에서는 아래 정보도 필요한 범위에서 처리합니다.

- Discord 로그인에 따른 사용자 ID·표시 이름·프로필 이미지와 참가 인증 정보
- 내전 명단·팀·포지션 배정, 참여·연결 상태와 운영자의 변경 기록
- 맵·영웅 선택, 선호·밴 투표와 결과
- 운영진이 작성하는 참가자 운영 메모와 수정 이력

특이사항·운영 메모에는 건강, 장애, 정치적 견해 등 민감한 개인정보를 기록하지 않습니다. 비밀번호나 Discord 인증 토큰을 참가자 입력란에 작성하지 않습니다.

## 2. 이용 목적

수집한 정보는 다음 목적으로만 사용합니다.

- 내전 참가자 식별
- 동명이인 및 중복 참가자 구분
- 참가자 명단과 유저 시트 관리
- 팀 밸런스 조정
- 내전 운영 및 참가자 정보 최신화
- 참가자 본인 확인, 실시간 공동 운영·밴픽 진행과 재접속 복구

## 3. 보관 기간

참가자 정보는 OWKR 서버 내전 운영에 필요한 기간 동안 보관됩니다.

다만 다음에 해당하면 정보를 삭제할 수 있습니다.

- 참가자가 삭제를 요청한 경우
- 최근 참가일로부터 3개월이 지난 경우
- 내전 운영상 정보가 더 이상 필요하지 않은 경우

브라우저에 임시 저장되는 개별 내전 명단과 팀 결과는 마지막 저장 후 최대 30분 동안 유효합니다. 브라우저가 닫혀 있으면 다음 조회·정리 시 만료 정보를 제거하므로 기기의 물리적 삭제 시각을 보장하는 의미는 아닙니다.

공동 운영 명단은 생성 후 3시간, 읽기 전용 결과 공유는 생성 후 24시간의 만료를 사용합니다. 실시간 밴픽 방·참가 인증·내전 운영 이력은 각 방과 운영 묶음의 만료에 따라 정리합니다. 방의 조회·접속만으로 보관 기간을 무제한 연장하지 않습니다. 로그인 상태·화면 테마·안내 진행 상태도 브라우저 쿠키나 로컬 저장소를 사용하며, 로그아웃·브라우저 설정으로 삭제할 수 있습니다.

서버 백업·복구용 이력·로그의 실제 보관 기한과 삭제 요청 반영 범위는 운영 설정을 추가 대조 중입니다. 모집 봇의 백업 7일·로그 30일 기준을 이 서비스에 임의로 적용하지 않습니다.

## 4. 저장 및 접근

2026년 10월 28일 운영 배포와 관리 화면에서 확인한 구성은 다음과 같습니다.

| 처리 경로 | 확인한 위치와 범위 |
| --- | --- |
| Vercel 화면·서버 함수 | 운영 서버 함수 리전은 서울(`icn1`). 웹 배포·인증과 내전 관리 요청을 처리 |
| Oracle 실시간 서버·서버 Redis 경로 | 서울 리전. 실시간 밴픽·인증·상태 복구와 서버 저장소 게이트웨이를 처리 |
| Upstash Redis | 연결된 저장소의 주 리전은 AWS 일본 도쿄(`ap-northeast-1`). 서버 저장소와 연동·장애 전환 경로에 사용 |

서울 함수 리전이나 국내 서버를 사용한다는 사실이 모든 정보의 국내 처리만을 뜻하지는 않습니다. 제공자와의 계약, 복제·백업 및 국외 이전 고지 사항은 추가 대조하고 있습니다.

참가자 전체 명단·운영 메모 등 관리 자료는 권한이 있는 운영진이 접근합니다. 실시간 참가자는 인증된 해당 내전에서 허용한 본인·팀·진행 정보를 확인하며, 운영자가 만든 결과 공유 코드를 가진 이용자는 그 공유 화면의 공개 범위를 만료 전까지 열람할 수 있습니다. 운영진만 모든 화면에 접근한다고 표현하지 않습니다. 해당 정보는 운영 목적 외로 판매하지 않습니다.
