## 1. 신청하기 전에

- 내전 시작 시간과 예상 진행 시간을 확인해 주세요.
- 해당 시간에 실제로 참여할 수 있을 때만 참가 체크를 눌러 주세요.
- [내전 공통 규칙](/owkr-docs/rules)을 먼저 확인해 주세요.

## 2. 참가 신청 직후

참가 체크를 누른 뒤 서버의 **내전 티어** 채널에 아래 양식에 작성해 주세요.

배틀태그 / 탱커 티어 / 딜러 티어 / 힐러 티어 / 기타 특이사항(원챔, 없으면 공란)

Discord 사용자 ID와 표시 이름은 관리자가 직접 입력하므로 참가자가 별도로 작성하지 않습니다.

**유의할 점**
- 자신의 실제 플레이 실력에 가장 가까운 티어로 작성해주셔야 합니다.
- 관리자가 추가로 요청한 참가 정보가 있을 경우 입력해주셔야 합니다.

## 3. 게임 시작 전

### 사설방 초대 허용

관리자와 참가자가 서로 친구 추가가 안되어 있는 경우, 설정에서 사용자 지정 설정방 초대를 활성화 해주세요.

### 대기와 입장

- 관리자가 공지에 작성한 시간까지 대기실 입장을 완료해 주세요.
- 관리자의 호출과 안내를 확인해 주세요.
- 대기 중에는 반복적인 대화나 행동으로 진행을 방해하지 말아 주세요.
- 초대를 받지 못했다면 관리자에게 알려 주세요.

## 4. 참가할 수 없게 된 경우

신청 후 참여가 어려워졌다면 **즉시 내전 관리자에게 알려야 합니다.**

지각이 예상되는 경우에는 예상 도착 시간도 함께 알려 주셔야 합니다.

공지된 입장 시간까지 연락 없이 입장하지 않은 경우 노쇼로 보며, 기본적으로 경고 1회가 부여됩니다.
