## 1. 참가 자격

참가하려면 아래 조건을 충족해야 합니다.

- 마이크 사용 가능
- 현재 시즌 배치 완료

### 시즌별 배치 기준

- **소프트 리셋 시즌 초** → 최소 **2포지션 배치**
- **소프트 리셋 시즌 말 ~ 일반 시즌** → **3포지션 배치**
## 2. 신청하기 전

참가 체크를 누르기 전에 아래 내용을 확인해 주세요.

- 내전 시작 시간과 예상 종료 시간
- 내전은 기본적으로 경쟁전 룰 3판 기준으로 진행됩니다.
- 예상 종료 시간까지 참여 가능한 경우에만 신청해 주세요.

## 3. 티어 정보 작성

참가 체크를 누른 뒤 **내전 티어** 채널에 아래 형식으로 작성해 주세요.

```text
배틀태그 / 탱커 티어 / 딜러 티어 / 힐러 티어 / 기타 특이사항
```

예시

```text
뿅뿅이#31243 / 그랜드마스터 4? / 그랜드마스터 2! / 그랜드마스터 4 / 딜러 트레 원챔
```

기타 특이사항이 없으실 경우 공란으로 작성하셔도 괜찮습니다.

### 선호 · 비선호 포지션 표시

- `!` : 선호하는 포지션 (최대 1개)
- `?` : 비선호하는 포지션 (최대 1개)

표시는 선택 사항이며, 각각 최대 1개까지만 사용할 수 있습니다.

### 작성 시 유의사항

- 실제 플레이 실력에 가장 가까운 티어를 작성해 주세요.
- 관리자가 추가 정보를 요청하는 경우 함께 작성해 주세요.
- Discord 사용자 ID와 표시 이름은 관리자가 직접 입력합니다.

## 4. 게임 시작 전

### 사설방 초대 허용

친구가 아니어도 초대를 받을 수 있도록 **사용자 지정 설정방 초대**를 활성화해 주세요.

### 대기 및 입장

- 공지된 시간까지 대기실에 입장해 주세요.
- 관리자의 안내를 확인해 주세요.
- 진행을 방해하는 행동은 삼가 주세요.
- 초대를 받지 못했다면 관리자에게 바로 알려 주세요.

## 5. 참여가 어려워졌다면

참가 신청 후 참여가 어려워졌다면 **즉시 내전 관리자에게 알려 주세요.**

지각이 예상되는 경우에는 예상 도착 시간도 함께 알려 주세요.

공지된 입장 시간까지 별도 연락 없이 입장하지 않으면 **노쇼**로 처리되며, 기본적으로 **경고 1회**가 부여됩니다.
