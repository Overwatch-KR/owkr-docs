# 개인정보 계약·국외 이전 검토

검토일: 2026-10-29. 범위: 시간을달리는소녀 봇 개인정보처리방침 0.4와 관련 운영 기록.
참가자·Balance 서비스의 처리방침은 이번 결론에 포함하지 않는다.

## 후속 범위 조정

운영자 요청으로 [Discord·커뮤니티 기준](discord-community-scope-2026-10-29.md)을 별도로 적용한다.
아래 내용은 당시 법적 운영 검토이며 모든 항목이 Discord 제출의 필수 선행 조건이라는 뜻은 아니다.
계약·국외 처리에 관해 확인하지 못한 사실 자체는 완료로 변경하지 않는다.

## 결론

보관·삭제 구현과 실제 백업 검증은 문서와 대조했다. 계약·국외 이전 고지는 보완이
필요하므로 이번 검토를 법률 적합성 인증이나 최종 시행으로 표시하지 않는다.
확인한 사실은 0.5 초안에 반영하고, 이전 0.4 공개 원문은 변경 이력에 보존한다.

## 확인한 사실과 아직 증명하지 못한 사실

| 항목 | 확인 결과 | 남은 작업 |
| --- | --- | --- |
| 운영 주체 | 운영자가 qtaghdi 개인 운영이라고 확인 | 존재하지 않는 OWKR 개인정보 담당 부서를 만들어 표기하지 않음. 실명·개인 전화번호 공개를 승인받은 것으로 해석하지 않음 |
| Oracle 계정 | 로그인된 구독 화면의 FREE_TRIAL·범용 크레딧 모델 확인, 운영 VM 도쿄 저장 확인 | 구독 화면에는 체결 계약 원문·예외 조항이 표시되지 않음. 계정별 적용 문서·수탁자 목록을 확보해야 함 |
| 일반 계약 경로 | 현재 Free Tier FAQ가 온라인 CSA v062223을 연결. CSA 제5.2조는 주문상 예외가 없으면 적용 DPA를 편입 | 과거 2014 Online Trial 약관을 현재 OCI 계정의 적용 계약으로 단정하지 않음. 공개 표준 계약 경로와 실제 주문 증빙을 구분 |
| Oracle DPA | 공개된 2025-08-14 버전은 처리자 역할, 재수탁자 목록, 선택 리전 저장과 국제적 지원 접근을 규정 | 해당 계정에 적용되는 버전·지원/복구 국가·재수탁자 목록은 별도 확인. 지원 문서 2121811.1 또는 공식 개인정보 문의 경로로 요청 가능 |
| Oracle 한국 계정 고지 | 운영자 계정 정보의 미국 이전을 따로 설명 | 이를 봇 참가자 DB 전체의 저장 위치 또는 수탁자 명칭 증명으로 대신하지 않음 |
| 문의 Gmail | 개인 Gmail이며 Google은 글로벌 서버를 운영 | 일본/한국 단일 국가 저장 또는 Workspace DPA 적용으로 표시하지 않음. 업무 위탁 여부·적용 계약·국가/보관 범위를 확인하거나 접수 방식을 재설계 |
| 현재 보관 집행 | 로그 30일, 백업 7일. 문의 종료 90일·대장 종료 1년은 운영자의 일일 절차 | Oracle 자체 계정·시스템 운영 데이터에 같은 보관 일수를 보장하지 않음 |
| 실제 삭제 검증 | VM 13개·Mac 5개 복원 검사와 운영 이미지의 가상 삭제 시험 통과. 실제 요청 0건 | 실제 접수·본인 확인·모든 복사본 파기·회신은 개별 요청 때 확인 |

계정·구독 번호, 개인 연락처, 금융 정보, 토큰과 요청 원문은 이 기록에 넣지 않았다.
공식 문의를 실제 전송하거나 새 계약·DPA에 동의하는 작업도 수행하지 않았다.

## 법령 대조

- 제28조의8과 시행령 제31조: 국외 처리의 법적 근거와 항목·국가·시점/방법·받는 자 및
  연락처·목적/기간·거부 절차와 효과를 구체화해야 한다. 도쿄 리전 표 하나로는 부족하다.
  DPA 체결, 일반 이용약관 게시, 참가 반응 자체가 별도 동의나 다른 이전 근거를 자동
  충족하지는 않는다. [현행 제28조의8][transfer], [현행 시행령 제31조][decree]
- 계약 체결·이행에 필요한 위탁·보관 경로는 이용자와의 실제 계약 및 필요성을 함께
  검토해야 한다. '무료 서버라서 필요'라는 이유만으로 채택하지 않는다. 별도 동의 경로를
  선택하면 고지·거부 처리·동의 기록을 수집 전 흐름으로 갖춰야 하므로 문구만 추가하지
  않는다. 어느 경로가 적용되는지는 이번 기록에서 확정하지 않는다. [현행 제28조의8][transfer]
- 제26조: 위탁 문서의 목적 제한·보호 조치와 수탁자/재수탁자 공개·관리 의무를 대조해야
  한다. 제공자의 일반 개인정보 안내만으로 계약 확인을 갈음하지 않는다. [현행 제26조][outsourcing]
- 제30조는 보호책임자 성명 또는 실제 담당 부서명과 연락처를 규정한다. 제58조제3항의
  친목 단체 운영에 해당하면 일부 조항의 적용 제외 가능성도 있다. 개인 운영·무료라는
  사실만으로 어느 한쪽을 단정하지 않는다. 이 예외가 제28조의8까지 면제하지도 않는다.
  실명 공개를 무조건 요구하거나 가상의 부서를 만들지 않는다. [현행 제30조][notice], [현행 제58조][club]

## 최종본에 필요한 국외 처리 표

아래는 확정에 필요한 필드 목록이다. 확인하지 않은 수탁자 법인명·국가·근거를 채워
넣은 공개 고지가 아니며, 빈 필드를 '전 세계'나 일반 정책 링크만으로 완료 처리하지 않는다.

| 처리 경로 | 채워야 할 내용 |
| --- | --- |
| Oracle VM·VM 백업 | 실제 수탁 법인·개인정보 연락처, 일본 저장 및 지원 접근 국가, 처리 항목, 이벤트 수신/저장 시점·암호화 통신 방법, 모집·복구 목적, DB·로그·백업별 기간, 이전 근거, 거부 절차/효과 |
| 국내 Mac 복사본 | 한국 보관·수동 복사와 7일 정리, 관리 담당·접근 제한. 한국 저장 자체를 국외 이전으로 잘못 분류하지 않음 |
| Gmail 문의 | 개인 Gmail의 실제 계약과 처리 역할, 받는 자·국가·연락처, 발송/수신 시점·방법, 문의 목적·처리 종료 90일과 제공자 자체 보관 범위, 근거, 거부 시 대체 접수 경로 |
| Discord DM | 문의 담당자의 처리와 Discord 자체 플랫폼 처리를 구분. Gmail 대신 DM을 쓴다고 국외 처리가 사라진다고 안내하지 않음 |

## 권장 후속 순서

1. 계정에 적용된 계약 원문과 Oracle 지원 접근·재수탁자 목록을 확보한다. 공식 문서의
   일반 계약 경로를 확인한 단계와 개별 계정 증빙을 확보한 단계를 구분한다.
2. 개인 Gmail을 계속 공식 접수 경로로 사용할 때의 계약·이전 범위를 확인한다. 변경이
   필요하면 새 접수 경로가 실제 작동한 뒤 약관·문의 안내·봇 설정을 함께 갱신한다.
3. 실제 운영 형태에 따른 처리·국외 이전 근거와 책임자 표기를 결정한다. 국내 서버로
   옮기더라도 Gmail·Discord 등 나머지 처리 경로는 별도로 검토한다.
4. 고지 표·이용자 권리·미성년자 처리·피해 구제 경로를 함께 대조하고, 필요한 절차를
   실제 적용한 뒤 시행일과 변경 안내를 정한다. 10명 기능 시험과 이 법적 판단은 별개다.

## 제공자에 확인할 질문 초안

Oracle에 문의할 때는 계정 번호·자료 원문을 처음부터 공개 문의에 싣지 않고 다음을
확인한다. 실제 전송은 별도 승인 대상이다.

> OCI Free Tier의 범용 크레딧 FREE_TRIAL 구독으로 일본 도쿄 Compute VM을 사용합니다.
> 한국 커뮤니티의 무료 Discord 내전 안내용 ID·표시 이름·티어 제출을 처리할 예정입니다.
> 이 구독에 적용되는 CSA 및 DPA 버전·예외 조항과 실제 수탁 법인명을 확인할 수 있는
> 문서를 안내해 주세요. 지원·사고 대응·복구 목적의 해외 접근 국가, 관련 계열사·재수탁자
> 목록과 개인정보 문의 연락처, 서비스 종료 후 삭제 조건도 확인하고 싶습니다.
> 개인정보나 운영 DB를 첨부하지 않고 계약·고지 범위를 확인하는 요청입니다.
