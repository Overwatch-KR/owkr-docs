호스팅에는 승인한 공개 안내 파일만 배포한다. 저장소 전체나 상위 `docs/`를 그대로
게시하지 않는다. 설정·환경 변수·DB·백업은 배포물에 포함하지 않는다. 호스팅의 방문
로그·쿠키 등도 실제 사용 여부를 확인하여 최종 처리방침에 반영한다.

사용자가 승인한 보관 정책은 내전 시작·취소 후 정리와 서버 탈퇴까지의 경고 보관이다.
30일·180일 보관안은 채택하지 않았다. 경고 보관은 무조건적인 영구 보관을 의미하지
않으며 수정·삭제 요청, 서비스 중단과 적용 법령에 따른 처리도 마련해야 한다.

기능·수집·보관·호스팅 변경 시 같은 변경에서 문서를 갱신하고 시행일과 변경 안내를
검토한다. 문서에 약속한 처리는 코드·운영 절차와 검증으로 뒷받침해야 한다.
로그·백업·문의 메일·요청 대장의 일수 기준 보관 기한은 아직 정해지지 않았다.
이번 검토에서 DB 보관 정책을 임의로 30일·180일 등으로 바꾸거나, 실제로 없는
자동 백업 파기를 추가했다고 표시하지 않는다.

공식 근거: [Discord 개발자 약관 §5](https://support-dev.discord.com/hc/en-us/articles/8562894815383-Discord-Developer-Terms-of-Service).

## GitHub Pages 초안 공개

공개 문서는 OWKR Docs의 Astro 빌드와 기존 Pages 배포를 사용한다.
주소는 `https://overwatch-kr.github.io/owkr-docs/gather-bot`이며 별도 봇 정책 사이트를 운영하지 않는다. 약관은 확정본을 공개한다. 개인정보처리방침과 지원 안내에는 초안 표시를 유지하고 위 최종 정책 체크리스트를 적용한다.

## 이용약관 1.0 확정 범위

- 사용자가 2026-10-28 당일 시행을 선택하여 그날 게시·시행한다. 게시 전 이용에 소급하지 않는다.
- 일반 변경 최소 7일, 불리하거나 중대한 변경 최소 30일 사전 안내. 침묵·계속 이용을 불리한 변경의 동의로 간주하지 않는다.
- 계획된 서비스 종료 최소 30일 전 안내, 종료 시 불필요한 개인정보의 파기와 예외 보관 근거를 구분한다.
- 서버 공지 채널 전송·개별 동의 수령·법률 적합성 인증을 완료했다고 표시하지 않는다. 이번 작업은 공개 사이트 게시와 이용약관 확정이다.
- 개인정보 보관 기한·국외 이전·책임자 표시·문의 경로 검증 등 남은 항목은 이 확정으로 완료 처리하지 않는다. Portal의 개인정보처리방침과 정식 운영 전환도 별도다.

## 봇 이름과 문서 날짜

공개 명칭은 **시간을달리는소녀**이다. `/gather-bot` 경로와 저장소 이름은 기존 링크 호환을 위해 유지한다. 개인정보처리방침·이용약관·요청 안내의 `publishedAt`은 모두 2026-10-27이며, 이전 저장소의 첫 정책 Pages 성공 배포 [40462894119](https://github.com/Overwatch-KR/owkr-gather-bot/actions/runs/40462894119) (2026-10-27 15:44 한국 시간), 커밋 `a0a4cb3b8e2e22c01344cb5ee9fd7f836c133702`에서 공개 내용을 확인했다. 초안 최초 공개일과 약관 시행일(2026-10-28)은 구분한다.

`publishedAt`은 이전·재배포 때 바꾸지 않는다. `updatedAt`은 실제 문서 갱신일로 수동 기록하고 빌드 시각으로 덮어쓰지 않는다. 문서 상단에 두 날짜와 버전을 표시한다. 이번 표기·화면 정리는 이용 조건과 보관 정책을 변경하지 않는다.
