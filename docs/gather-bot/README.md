## 봇 이름과 문서 날짜

공개 명칭은 **시간을달리는소녀**이다. `/gather-bot` 경로와 저장소 이름은 기존 링크 호환을 위해 유지한다. 개인정보처리방침·이용약관·요청 안내의 `publishedAt`은 모두 2026-10-27이며, 이전 저장소의 첫 정책 Pages 성공 배포 [40462894119](https://github.com/Overwatch-KR/owkr-gather-bot/actions/runs/40462894119) (2026-10-27 15:44 한국 시간), 커밋 `a0a4cb3b8e2e22c01344cb5ee9fd7f836c133702`에서 공개 내용을 확인했다. 초안 최초 공개일과 약관 시행일(2026-10-28)은 구분한다.

`publishedAt`은 이전·재배포 때 바꾸지 않는다. `updatedAt`은 실제 문서 갱신일로 수동 기록하고 빌드 시각으로 덮어쓰지 않는다. 문서 상단에 두 날짜와 버전을 표시한다. 이번 표기·화면 정리는 이용 조건과 보관 정책을 변경하지 않는다.

## 공개 변경 이력 관리

`/gather-bot/changes`는 주요 공개 버전의 본문을 이전 버전과 비교한다. 최초 초안·파일럿 운영 반영·모집 미완료 취소·약관 확정 기록은 당시 공개 Git 커밋의 본문을 보존했다. 모든 커밋을 나열하는 페이지는 아니다.

공개 문서를 수정할 때는 배포 중인 이전 본문을 먼저 `src/content/policy-revisions`에 보존한다. 문서 종류, 공개 날짜, 문서별 고유 순서, 당시 확정/초안 상태, 변경 요약과 전체 커밋 해시를 사용한 GitHub 원문 주소를 기록한다. 과거 명칭과 문구는 고치지 않는다. 현행 원본의 `version`, `updatedAt`, `changeSummary`와 `CHANGELOG.md`를 함께 갱신한다. 최초 발행일은 유지한다. 같은 날의 여러 변경은 순서로 구분한다.

현행 버전은 원본에서 자동으로 가져오므로 별도 복제하지 않는다. 초안이 섞인 이력 페이지는 검색에서 제외하며, 검토 메모와 비공개 정보는 이력에 넣지 않는다. 날짜·버전 등 메타데이터와 화면만 바뀐 경우 본문 차이가 없을 수 있다. `pnpm check`는 행 비교 검증, 형식 검사와 정적 빌드를 실행한다.

## 2026-10-28 추가 확정·대조

운영자가 로그 최대 30일·VM/Mac 백업 생성 후 7일·문의 종료 후 90일·최소 요청 처리 기록 종료 후 1년을 승인했다. 내전 DB·경고 보관 기준은 유지한다. Mac 한국 보관·FileVault 사용, 이메일 수신·회신·Discord DM 수신을 운영자가 확인했다. 담당 공개 표기는 qtaghdi · 내전 총관리자로 확정했다. 문의 안내 1.0은 공식 접수 경로·자료 최소화·처리 결과 구분과 복원 전 삭제 반영을 안내한다.

봇 PR #18의 백업·로그 자동 정리와 Mac LaunchAgent를 적용 후 실제 상태·복원 검사를 기록한다. 메일·요청 기록은 담당자가 매일 만료와 파기를 확인한다. 잘못된 백업 생성 기록·미완성 복사본은 오류 점검 대상이다. 개인 자료를 보존하기 위한 임의의 예외 기간을 추가하지 않는다.

개인정보처리방침 0.4는 국외 이전 근거·수탁자 계약과 세부 고지·책임자 법정 표시 대조가 남아 최종 처리방침으로 표시하지 않는다. 참가자/Balance 안내도 현재 별도 실시간 서버·저장소의 실제 제공자·리전·처리 항목을 확인 중이며 기존 문서만으로 전체 검토 완료를 선언하지 않는다.

## 운영 적용 검증

봇 PR [#18](https://github.com/Overwatch-KR/owkr-gather-bot/pull/18)은 main `12b5b10`에 병합했다. 도쿄 VM은 journald 로그 드라이버로 정상 재생성했고 단일 프로세스·재시작 횟수 0을 확인했다. `owkr-retention.service` 성공, 시간별 타이머·logrotate 타이머 활성화, 최신 백업의 격리 복원·SQLite 무결성·외래키 검사가 통과했다. Discord 읽기 전용 사전점검에서 필수 6개 명령과 권한을 확인했다. Mac LaunchAgent 설치와 첫 실행 성공을 확인했으며, 기존 복사본은 아직 7일 이내라 삭제 대상이 없었다. 개인 요청 대장은 한국 Mac의 접근 제한 폴더(700), 파일(600)에 준비했다. 메일·요청 기록 정리는 운영 담당자의 일일 절차로 유지한다.
